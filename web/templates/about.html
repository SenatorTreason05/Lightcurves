About This Platform

The X-ray Lightcurve Analysis Platform is a web-based tool for analyzing X-ray observations from the Chandra X-ray Observatory. It provides automated, comprehensive analysis of lightcurves with advanced variability detection and periodogram analysis.

Features

🔥 Flare Detection

Automatic detection of statistically significant flares using robust statistics. Flares are identified as count rate increases >3σ above the median.

⚡ Dip Detection

Identifies significant dips in count rate (>2σ below median), useful for detecting eclipses, absorption events, or obscuration.

📊 Improved Lomb-Scargle

Edge-corrected periodogram analysis with False Alarm Probability levels. No more artifacts! Clear significance assessment for periodic signals.

🎨 Multi-Band Analysis

Extracts lightcurves in 5 energy bands (Ultrasoft, Soft, Medium, Hard, Broadband). Computes 4 different hardness ratios for spectral evolution tracking.

📈 Bayesian Blocks

Adaptive binning to identify count rate changes with three different prior probabilities (p0 = 1, 5, 10) for sensitivity tuning.

🌐 Global Access

No local installation required. Access pre-processed data instantly. Submit new analysis jobs with custom parameters.

How It Works

  1. Search: Query the Chandra Source Catalog for sources near your target
  2. Browse: Explore available sources and their observations
  3. Analyze: View comprehensive analysis including plots, flares, dips, and periodograms
  4. Export: Download CSV data and high-quality SVG plots
  5. Reprocess: Submit jobs with different parameters (binsize, etc.)

The Analysis Pipeline

Each observation is processed through a comprehensive pipeline that generates:

  • 14-panel comprehensive plot including:
    • Broadband count rate with flare/dip markers
    • Bayesian Blocks segmentation (3 variants)
    • Separated energy band count rates
    • Hardness ratio evolution
    • Cumulative counts
    • Lomb-Scargle periodograms (4 variants)
    • Gregory-Loredo variability
    • Fractional area tracking
  • CSV data file with all photometry
  • Postage stamp images (sky and detector coordinates)
  • Variability metrics and statistics

Understanding the Results

Flares and Dips

Flares (marked with orange stars ★) are significant increases in count rate. They're detected using the Median Absolute Deviation (MAD) method, which is robust to outliers.

Dips (marked with cyan triangles ▼) are significant decreases in count rate. These can indicate eclipses, absorption events, or the source passing behind obscuring material.

Lomb-Scargle Periodogram

The periodogram searches for periodic signals in the data. The colored dashed lines show False Alarm Probability (FAP) levels:

  • Green (10%): Possibly significant
  • Orange (5%): Likely significant
  • Red (1%): Very likely significant
  • Dark red (0.1%): Extremely confident

If a peak is above the red line (1% FAP), you can be very confident it represents a real periodic signal!

Hardness Ratios

Hardness ratios track spectral evolution by comparing count rates in different energy bands:

  • HR_HS: (S-H)/(S+H) - Hard vs Soft
  • HR_MS: (S-M)/(S+M) - Medium vs Soft
  • HR_SMH: (S-(M+H))/(S+M+H) - Soft vs Higher energies
  • HR_MHSU: ((S+U)-(M+H))/(S+U+M+H) - Full band comparison

Changes in hardness ratios indicate spectral evolution, which can be correlated with flares, dips, or other variability features.

API Access

Programmatic access is available through our REST API. Documentation:

  • GET /api/sources - List all sources
  • GET /api/sources/{name} - Get source details
  • GET /api/observations/{obsid} - Get observation details
  • GET /api/observations/{obsid}/data - Download CSV data
  • GET /api/observations/{obsid}/plot - Download plot
  • POST /api/analyze - Submit analysis job

All responses are in JSON format (except data/plot downloads).
